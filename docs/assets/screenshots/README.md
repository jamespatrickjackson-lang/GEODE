# GEODE screenshot provenance

These four images are web-optimized copies of authentic GeoSee / Utah FORGE screenshots supplied by the repository owner for public portfolio use on 12 November 2026.

- Source: original PNGs in the owner's local Downloads folder; no stock or AI-generated imagery.
- Original dimensions: 3840 × 2160 (UHD/4K).
- Published dimensions: 1920 × 1080 JPEG, 85% quality, high-quality bicubic downsampling. No crop, recompositing, text overlay or scientifically meaningful adjustment was applied.
- All four screenshots are outputs from the GeoSee visualization application. Exact visible layer IDs, scientific data products, scene/page state and camera poses cannot be proven from the pixels alone.
- Visual evidence supports the presence of terrain and subsurface renderings, not registration accuracy, numerical geophysics agreement, subsurface interpretation, or engineering acceptance.
- The original full-resolution PNGs remain outside GitHub. Keep them for future side-by-side verification.
