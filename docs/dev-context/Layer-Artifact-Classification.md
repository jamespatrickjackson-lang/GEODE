# Layer / Computed Artifact Classification

## Purpose

This is a docs-only classification matrix for current GeoVox layers, data artifacts, and computed artifacts. It is not runtime state, not accepted scope, and not permission to edit manifests, visibility, data, prep scripts, or source code.

## Guardrails

- Observed: Bloat reduction means reducing structural confusion, not reducing rendering quality, dataset richness, or computed-artifact capability.
- Observed: Seismic is needed and underway. Do not park, hide, delete, or downgrade seismic by assumption.
- Observed: Computed artifacts such as isolines, isobands, contours, heat maps, threshold surfaces, slices, scalar volumes, meshes, tiled point clouds, seismic products, legends, and provenance wrappers are core GeoVox capability.
- Proposed only: Load policy recommendations below are classification prompts for human review. They are not committed scope.
- Rule: Do not call an artifact technically accurate unless source, CRS/transform, units, parameters, stats/counts, and provenance/status are all evidenced.

## Evidence Vocabulary

| Field | Meaning |
| --- | --- |
| artifact family | Raw source, intermediate processing, computed analytical artifact, render-ready artifact, QA/validation artifact, presentation artifact, provenance/status wrapper, future/placeholder, or unknown. |
| computation role | Source only, parsed/transformed, interpolated, gridded, contoured, thresholded, tiled, downsampled, render-transcoded, QA/statistical, or unknown. |
| rendering role | Default visual, high-fidelity client-facing, technical credibility, QA/validation, optional advanced, future/placeholder, or too risky/unclear. |
| load policy recommendation | Load on project open, load by page, load on toggle, QA-only toggle, or unclear / human review. |
| computation/provenance evidence | Records whether inputs, script/tool, CRS/transform, units, parameters, counts/stats, and provenance/status were observed. |
