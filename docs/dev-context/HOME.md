# Dev Context Home

## Purpose

This folder is an AI-readable lab book and control-plane trace rail around the Geovox / GeoSee repo. It helps future humans and agents understand current state, source records, proposed interpretations, acceptance status, verification receipts, and scope refinement without treating scattered notes as active truth.

## Governing Rule

“Human intent enters as messy context. AI may translate, propose, and route. Software owns deterministic state. AI interpretation remains proposal until accepted. Verification and receipts preserve the trace. Human review promotes accepted state.”

## Non-Purpose

- This is not the official DHF.
- This is not the app runtime.
- This is not a replacement for source files, manifests, or tests.
- This is not a junk drawer for every old handoff note.
- This does not implement SRI or Processware inside the app.

## Use Pattern

1. Register deterministic sources before interpreting them.
2. Record AI interpretation as inference, not truth.
3. Promote accepted state only after human review.
4. Attach verification receipts to meaningful changes.
5. Keep app implementation separate from this control-plane rail.
