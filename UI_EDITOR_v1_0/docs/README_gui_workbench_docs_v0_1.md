# 1. Important Status Notice

This document set is an **initial concept sketch** for the GUI Workbench.

No final decisions have been made.

The documents in this package are intended to probe, clarify, and refine the idea before any formal build planning or Version 1 definition.

They should not be treated as:

- approved product requirements
- approved technical architecture
- implementation instructions
- a build plan
- a final scope definition
- a final package schema
- a final validation rule set
- an approved GOC integration plan

Some documents contain early requirement or architecture language because they are exploring what a future Version 1 definition may need to address. That language is provisional and should be reviewed before being promoted into any formal plan.

---

# 2. How to Use This Package

Use this package to understand and review the GUI Workbench concept.

The intended workflow is:

```text
read the orientation docs
→ understand the concept
→ review boundaries and assumptions
→ inspect unresolved questions
→ decide what should be accepted, rejected, deferred, or revised
→ only then begin formal build planning
```

The reviewer open-questions index is the main single-point review document.
