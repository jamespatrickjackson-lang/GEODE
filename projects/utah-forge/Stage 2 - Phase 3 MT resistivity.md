# Stage 2 - Phase 3 MT Resistivity

Updated: 2026-05-12

## Purpose

Stage 2 finishes the Utah FORGE Phase 3 MT resistivity renderer/data-density pass.

The goal is to upgrade from the 90,000-point QA preview plus authored slice layer to a full-density, scalar-aware MT visualization using every positive-resistivity model cell center from the updated Phase 3 MT inversion model.

A follow-on Stage 2 element adds a preview-derived approximate ground cap from the existing 90,000-point MT resistivity model preview only. This is a visual ground-layer aid only; it is not terrain, interpreted geology, wells, faults, or seismic.

This stage is not the guided story/page pass.

## Hard Boundary

Do not start seismic until the user explicitly says to start.

Blocked until later user direction:

- Phase 3 seismic analysis
- Southwestern/regional MT
- wells
- faults
- terrain/context surface
- infrastructure
- microseismic events
- story/page presentation build
