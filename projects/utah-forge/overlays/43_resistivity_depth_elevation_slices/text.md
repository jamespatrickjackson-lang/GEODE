# Resistivity Depth / Elevation Slices

Status: proposed / needs_review

This page addresses Jane's request for 2D resistivity at a selected depth or elevation.

- Current support: authored MT slice meshes.
- Target product: interactive depth/elevation slice extraction.
- Depth-below-surface and fixed-elevation slices are different products.
- Resistivity should use log intervals with real Ohm-m labels.

Missing / unresolved: interactive extraction, filled contour generation, contour labels, interval controls, and warnings for too many contour lines.
