**16A Borehole Logs Source Ingest**

This page shows the new source-derived borehole-log layer on the validated 16A(78)-32 trajectory.

Renderable tracks are limited to machine-readable GDR 1292 gamma curves. HCGR and HSGR each contribute 4334 measured-depth samples and are mapped along the as-drilled path with vertical exaggeration fixed at 1.0.

58-32, 68-32, 78-32, and DLIS/PDF-only packages remain inventoried source material, not rendered claims. The 78-32 cuttings interval table is parsed, but blocked until a validated render trajectory is available.

The Bore Holes layer provides the trajectory context; the Borehole Logs layer provides offset source-derived curves and provenance/readout metadata.

*Sources -> GDR 1292, GDR 1006, GDR 1153, GDR 1283, GDR 1440, GDR 1516, GDR 1531*
