Resistivity volume overview.

This page uses the existing source-derived MT inversion volume and a faint full-density point-cloud context layer.

Status: source-derived.

Values are framed as log10 resistivity in Ohm-m, using the existing layer color ramp and scalar range from the processed Utah FORGE MT artifacts.

The volume is a browser-ready visualization of the MT inversion model from the existing cell-center package. It is not interpreted geology, a target, or a resource estimate.
