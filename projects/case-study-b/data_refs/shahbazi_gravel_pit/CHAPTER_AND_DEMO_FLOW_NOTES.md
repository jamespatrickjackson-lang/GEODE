# Chapter And Demo Flow Notes

These notes are for the pass after the first real Shahbazi-derived visual layer is loaded in GeoSee.

## Case Study B Chapter Shape

Keep the current five-page Case Study B structure, but retune the camera path around real geometry:

1. Overview
   - Show the whole gravel pit extent.
   - Establish that the base layer comes from an open UAV/TLS dataset.

2. Bench Walkthrough
   - Use the highest-fidelity asset available, preferably TLS sub-zone or textured mesh.
   - Emphasize close-range surface detail and audience comprehension.

3. Anomaly Story
   - Use illustrative overlays sparingly.
   - State that overlays are synthetic unless replaced by reviewed real technical data.

4. Planning / Governance
   - Show access, stockpile, slope, runoff, and conformance concepts.
   - Keep language source-forward and review-oriented.

5. Public Communication
   - Use the calmer Audience Lens.
   - Emphasize visual explanation, restoration, viewpoint, and plain-language interpretation.

## UVic / Provenance Story

The strongest technical story is independent validation:

- UAV photogrammetry produces dense geometry.
- TLS point cloud covers a 30 x 40 m sub-zone.
- Cross-checking UAV reconstruction against TLS gives a clear data-integrity narrative.

Do not overstate accuracy until actual registration quality is measured.

## CEO / Commercial Story

The strongest commercial story is visual fidelity and repeatable workflow:

- Open dataset becomes a high-fidelity walkthrough.
- Same project spine supports investor, public, government, and regulatory readings.
- Flythrough can be synthesized from still-image / mesh / point-cloud assets.

## Bingham / Woodjam / Gravel Pit Flow

Alternative CEO order:
